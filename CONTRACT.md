# Контракт переноса (для разработки)

PHP 8.3, без namespace/framework. lib/db.php: db(): PDO, nowMs(): int, uuid(): string, transaction(callable). lib/rules.php: ShopError(message,status=400,code='INVALID_REQUEST'); deliveryCost, canTransition. lib/shop.php: getCatalog(), getSettings(), resolveCart(array $identity): string, getCart(string), changeCart(string,array), quote(string,string), createOrder(string,array,array), listOrders(array,bool=false), orderDetails(string,array), claimGuestOrders(array), updateOrderStatus(string,string). Формы/массивы camelCase как в исходных lib/types.ts и lib/shop.ts. Все цены в этих функциях — копейки; даты — миллисекунды.

lib/admin.php: saveProduct(array), saveSettings(array), saveUpload(array $_FILES element): string URL. Входящие цены формы priceRub / variants[][priceRub], рубли строкой; exact conversion to cents. checkbox available/isBestseller/isSeasonal; stock пусто=null, expectedStock пусто=null. Product form variants[][id,label,volumeMl,priceRub]. Settings feeRub/freeFromRub/minimumRub/city. Серверные функции проверяют данные, маршрутизатор проверяет admin.

lib/auth.php: startSession(): void, identity(): array guestHash/userId?/role?/name?, registerUser(login,password): void (вход сразу), loginUser(login,password,admin=false): void, logoutUser(): void, csrfToken(): string, checkCsrf(token): void, requireAdmin(array): void, rateLimit(key,max,windowSeconds): void. auth использует db(), nowMs(), uuid(), ShopError. Не определять общие утилиты повторно. Cookies 30d guest,7d session,1y notice. Пароли scrypt совместимые с Better Auth.

Главный контроллер принадлежит root: public/index.php + router.php; helper e(), money(), csrfField(), old(key,default=''), formAction(action,returnTo='') печатает hidden csrf/_action/returnTo. view(page,array data) устанавливает $catalog,$person,$cart,$pageData,$old,$errors. $pageData: checkout quote?+fulfillment+idempotencyKey, order order, admin orders+editingProduct?, account orders. $errors массив строк; $old массив сохранённых входов без пароля. $catalog — getCatalog(). $cart — getCart(). $person — identity().

UI agent owns views/*, public/style.css, public/app.js, lib/view_helpers.php (only UI helpers, unique names). Сохранять внешний вид исходного сайта, классы CSS. layout оборачивает page template через $content. Template files home/menu/cart/checkout/login/account/order/admin/legal/error + product-card.php. Страницы /,/menu,/cart,/checkout,/login,/account,/orders/{id},/admin,/privacy,/terms,/cookies. /login?admin=1. Формы POST /action, _action allowlist: login,register,logout,cart_add,cart_update,cart_remove,cart_clear,checkout,orders_claim,admin_product,admin_status,admin_settings,admin_upload,cookies_accept. Каждый form включает formAction(). Изменения корзины quantity,itemId,productId,variantId. checkout поля исходной checkoutSchema, hidden fingerprint+idempotencyKey; fulfillment изменяется GET /checkout?fulfillment=... (ссылки/форма), PHP заново считает quote. order status поля orderId,status. upload поле image. admin_product id,name,description,category,priceRub,image,available,stock,expectedStock,isBestseller,isSeasonal,variants. Admin edit link /admin?product={id} или ?product=new. Logout POST.

UI показывает реальные рабочие формы, сохраняет выбор/ошибки, keyboard navigation/modal focus. Без AJAX; vanilla JS меню/диалоги/фильтры/добавление полей вариантов. Точные остатки только admin. Inline SVG icons можно простые из исходных.

Runtime config: getenv DATABASE_PATH or ROOT/.local/bakery.sqlite; UPLOADS_PATH or ROOT/.local/uploads; APP_URL default http://127.0.0.1:3083. ROOT defined bootstrap. config via optional ROOT/.local/config.php array assigned to $config by bootstrap; env first, then $config. DB helper does not load private config itself, root does. Tests can setenv before require. No production seed or external notifications.
